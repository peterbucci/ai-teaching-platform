Result and scope

The selected-assignment Teaching Desk is replaced with a teacher decision workspace across authorized assignments: evidence-backed review prompts, assignment rail, saved private work, recent responses, and contextual next actions. No shared shell, navigation, other workspace, schema, or permission service was changed.

Missing-data decisions and remaining deviations

  • Authority remains the union of teacherAssignments and existing class/lesson ownership checks. No global course registry or cross-class student total was created. A true course selector needs an approved course-membership contract.
  • Priority counts come from existing authorized metrics. Denominators name enrolled or assessed students within the assignment; counts are never added across concepts/classes. A multi-concept answer may create multiple concept review prompts. No mastery, due dates, behavioral inference or trends were invented.
  • The prototype's named hypotheses, repeated/contrary counts and direct concern-to-draft matching require an agreed authorized pattern-to-workflow projection. Current concept prompts are useful but not full pattern parity. This is a deliberate scope boundary requiring review, not a fixture difference.
  • Section filter chips remain absent. Evidence-origin filtering is supported. Adding section filtering is a separate local interaction decision for integration review; it is not claimed complete.
  • Intervention listing retains the existing 30-most-recent limit per assignment, with a visible notice at the cap. Complete older-draft recovery requires a paginated owned draft listing contract. Saved drafts only: listing browser-local unsaved work would need a scoped recovery index.
  • Recent activity is saved student answers, not an audit of all teacher actions. A full activity feed needs an authorized event source. The supplied prototype Overview has no separate recent-activity panel.
  • The shared shell context band and return labels are unchanged. Agent K owns contextual-return integration. Overview-origin links carry fresh assignment scope and returnTo=desk; lesson editor resume uses its existing canonical route.
  • Page-local reads use existing authorized services with at most four assignment loads concurrently. This avoids a parallel metrics service; it is not a single transaction across the entire workspace and has not been load-tested at large course scale.

Review and explicitly accept these bounded deviations before calling complete prototype parity. No request to waive authorization or fabricate data is needed.
