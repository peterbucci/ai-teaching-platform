Reproduction

Use the exact application source and an isolated fictional database with providers disabled. The browser helper is opt-in and read-only after sign-in: browser-check.mjs. Supply --origin (loopback), a fresh --output, --modules (directory containing Playwright), --browser (Edge/Chromium executable), --fixture (fictional lesson/empty-account descriptors), --env (private runtime config with empty OPENAI_API_KEY), and --baseline (before.json). The executed fixture descriptors preserve exact synthetic IDs/source references; recreating the temporary long-title draft requires a fresh descriptor.
