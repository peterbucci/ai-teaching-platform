A single cable becomes twice as long. Packet size, link transmission rate, and propagation speed stay unchanged. What happens to transmission delay and propagation delay? Explain why.

Both delays double. The bits have to travel twice as far, so it takes twice as long to send them and twice as long for them to arrive.

Reading this question uses

P07 · Three components of latency

We often think of latency as having three components. First, there is the speed-of-light propagation delay. … Second, there is the amount of time it takes to transmit a unit of data. This is a function of the network bandwidth and the size of the packet in which the data is carried. Third, there may be queuing delays inside the network.

P08 · Latency = Propagation + Transmit + Queue

Latency = Propagation + Transmit + Queue; Propagation = Distance / SpeedOfLight; Transmit = Size / Bandwidth — where Distance is the length of the wire over which the data will travel, SpeedOfLight is the effective speed of light over that wire, Size is the size of the packet, and Bandwidth is the bandwidth at which the packet is transmitted.

P12 · Latency, delay and one-way vs round trip

When we are referring to the specific amount of time it takes a signal to propagate from one end of a link to another, we use the term propagation delay. Also, we make it clear in the context of the discussion whether we are referring to the one-way latency or the round-trip time.

Marking guide only you and the evaluator see this

Point 1 Transmission delay Identifies packet size and transmission rate as the determinants of transmission delay.

Point 2 Propagation delay Identifies cable length and propagation speed as the determinants of propagation delay.

Model answer. Transmission delay is unchanged because it is packet size divided by transmission rate, both fixed. Propagation delay doubles because it is cable length divided by propagation speed.

Partial credit. One correct effect with the other missing or wrong is partial. Both effects correct without explanation are partial and need a brief reasoning probe.

Approved hint. Write each delay as a ratio. Which ratio contains cable length?
