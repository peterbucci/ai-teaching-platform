The `upstream` directory preserves the source section file, license, and README exactly as returned for the fixed revision. The full performance source file is retained for provenance; only section 1.5.1 is assigned to the tutor. The original excerpt in `reading-original.rst` preserves lines 14 through 187 without rewriting. Passage records preserve exact line spans and hashes.

The readable `reading.md` view reflows paragraphs and renders source notation. It adds headings and passage labels, omits figure images and their captions, and marks those omissions. ## Upstream wording discrepancy

The applicable repository [LICENSE at the fixed source revision](https://github.com/SystemsApproach/book/blob/5deec5e741e2b8c0bc44566108a24cb783c2c7de/LICENSE), Section 2(a)(1), explicitly permits reproducing, sharing, and adapting the licensed material under CC BY 4.0, subject to its conditions. The [upstream README](https://github.com/SystemsApproach/book/blob/5deec5e741e2b8c0bc44566108a24cb783c2c7de/README.rst) contains apparently inconsistent wording about derivative-work rights. That wording is not proof that separate permission is required for adaptations covered by the license.

The project's [Contributor License Agreement](https://github.com/SystemsApproach/book/blob/5deec5e741e2b8c0bc44566108a24cb783c2c7de/CLA.rst) also describes extracts, new works, and adaptations under CC BY. It concerns contributions and provides supporting context, not a substitute for the license covering the original textbook.

The contradictory README wording was added in the [July 15, 2022 commit, "sync epub across all books"](https://github.com/SystemsApproach/book/commit/5b72343a0cf3cd57e9fc80376511faecf45a8ca7). Other Systems Approach books, including [5G Mobile Networks](https://github.com/SystemsApproach/5G) and [Software-Defined Networks](https://github.com/SystemsApproach/sdn), use CC BY-NC-ND, which restricts sharing adaptations. Wording carried over from those books is a possible explanation, but this is an inference, not an author-confirmed mistake.

This package preserves both original notices and does not claim legal clearance or author confirmation. Follow the attribution and change-notice requirements above, and check any separately credited third-party material before reuse; the license covers only rights the licensor has authority to grant.
